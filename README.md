# Link Grabber

**Extract direct download links from file hosting sites on Android** — then paste them into any download manager (1DM, ADM, IDM…).

### ⬇️ [Download the latest APK](https://github.com/sgs2ofameer/Link-Grabber-Releases/releases/latest)

Open the latest release and tap the `LinkGrabber-vX.Y.Z.apk` file under **Assets**. After installing once, the app updates itself from this page.

## Features

- Built-in browser that captures the **final file link** when a site starts its download, and copies it automatically
- Works with DataNodes, GoFile, AkiraBox, DataVaults, FileDitch, FileKeeper, Cybar and similar sites
- Copy, share, open in a download manager, or copy with cookies & headers
- Chrome-like tabs, favorites and Google search from the address bar
- Built-in ad blocker with auto-updating filter lists (EasyList, EasyPrivacy, Peter Lowe, uBlock Badware…), custom lists and your own rules
- Blocks ad pop-ups and redirects
- In-app updates
- Material 3 design, light & dark themes, English and Arabic

## How to use

1. Open the file page (paste the link, or share it to the app from your browser).
2. Complete the site's steps and tap its **Download** button.
3. The direct link appears in **Links** and is copied — paste it into your download manager.
